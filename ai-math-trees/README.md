# AI Mathematics Tree Maps

Public route: `https://raghav-one.github.io/math/ai-math-trees/`

```
ai-math-trees/
├── index.html                 # Map page
├── styles.css                 # Responsive layout and tree appearance
├── app.js                     # Navigation and keyboard interactions
├── diagrams/
│   ├── tree-data.js           # Six concept trees and their dependencies
│   └── render-trees.js        # SVG tree renderer
└── README.md
```

The maps cover foundations, linear algebra, functions and calculus, probability and statistics, optimization and generalization, and modern AI model mathematics. They are a visual companion to the main Math for AI curriculum, not a replacement for worked examples and prose.
